# Security

This is a static site with no accounts, no backend and no user data on a server. The checklist and preferences live
only in your browser's local storage.

If you find a security problem (for example, a listed link that now points to a malicious page, or an issue in the
site's code), please email **kambojpushkal@gmail.com** instead of opening a public issue. You'll get a reply within a
few days.
