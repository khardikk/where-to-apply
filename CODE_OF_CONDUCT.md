# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep feedback about the work. Harassment, insults, discrimination,
and posting someone's private information are not okay anywhere in this project: issues, pull requests, reviews or
discussions.

The list itself follows the same spirit: it links only to public, professional profiles and never to anyone's
personal contact details.

To report a problem, email **kambojpushkal@gmail.com**. Reports are kept confidential. The maintainer may remove
comments, close issues or block accounts that break these rules.
